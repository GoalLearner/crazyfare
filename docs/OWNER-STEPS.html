CrazyFare: the parts only you can do

All six phases are built. These are the dashboard, upload and publish steps that need your Roblox account. Each one is a number pasted into src\shared\Config.luau; the game works without them, it just hides the feature until the id exists.

1. Publish the place and turn on saving

  1. In Studio: File → Publish to Roblox. Pick a name (CrazyFare), set it private for now.
  2. Home → Game Settings → Security: turn on Enable Studio Access to API Services. Until this is on, Gems, vehicles and leaderboards reset every time you stop a test (they use an in-memory store in Studio).
  3. Game Settings → Places → your place → Max Players: 6.
  4. Before the first public test, set Round.MinPlayers = 2 in Config so a round doesn't start for a lone player.

2. Create the products and passes

Creator Dashboard → your experience → Monetization. Create each item, copy its id, paste it into the matching line in Config.Monetization. Anything left at 0 shows as COMING SOON in the shop.

4. Art, when you're ready

The game runs on parts on purpose. When you want real models, the order that pays off fastest: the Yellow Cab (on screen every second), then the six items (the banana is a placeholder), then the five other vehicles, then landmark buildings. Any model works if it keeps the contract in VehicleBuilder.luau: a Chassis part, four wheel attachments, and the named parts.

5. Rebuilding after you paste ids

cd C:\dev\crazyfare
.\scripts\check.ps1

That typechecks, lints and rebuilds build\CrazyFare.rbxl. Or ask me to do it.

Never

  • Sell anything that changes passenger HP, item damage, car speed or the quota. The shop has none, keep it that way.
  • Put a licensed character, car or song in. Everything in the game is original.
