Putting the Kenney art in

Six CC0 model kits and nine CC0 audio packs are downloaded to C:\dev\crazyfare\assets. Each model is one import in Studio, then one command. Start with the taxi; everything else is the same moves.

1. Import one model (the taxi)

  1. Open the latest build in Studio (ask me to "open" it). Don't start a test; stay in edit mode.
  2. Top menu File, then Import 3D.
  3. Pick C:\dev\crazyfare\assets\kenney\car-kit\Models\FBX format\taxi.fbx.
  4. In the import window, leave the defaults. Make sure Upload to Roblox is on (that's what turns the file into a mesh your game can use). Press Import. It appears in the Workspace as a model named taxi.
  5. Click that model once in the Explorer so it's selected.
  6. At the bottom of Studio, in the Command Bar, paste this and press Enter: 
    require(game.ServerScriptService.Server.Studio.VehicleRig).Rig(game.Selection:Get()[1], "YellowCab")
    The Output says [VehicleRig] YellowCab rigged and the model moves to ReplicatedStorage, VehicleTemplates. The game now spawns the mesh taxi instead of the parts one.
  7. If the car drives backwards, the mesh faces the wrong way: select the model, press Ctrl+R twice to rotate 180 degrees, and run the command again.
  8. File, then Save to Roblox so the imported meshes stay in the place.

3. Items

Same import, different landing spot. Import food-kit\Models\FBX format\banana.fbx and tomato.fbx. In the Explorer, drag each into a folder named ItemModels inside ReplicatedStorage (create it with right-click, Insert Object, Folder), and rename the models to exactly Banana and Tomato. The game scales and places them itself. lemon.fbx is ready for when Lemon Nitro gets a world object.

4. Buildings (optional, bigger change)

Import any of city-kit-commercial\Models\FBX format\building-a.fbx through building-k.fbx and drop them into ReplicatedStorage, MapModels, Buildings (two folders to create). When that folder has anything in it, the City generator uses those meshes for every building lot instead of boxes, scaled to fit the lot. Try three or four first and look at a round before importing all eleven.

Streetlights, traffic lights and signs from city-kit-roads are next on my side once the buildings are in; the generator already places parts versions in the right spots.

5. If something looks wrong

  • Car floats or sinks: tell me how many studs off; it's one number in VehicleRig.luau.
  • Car is huge or tiny: the rig scales to 11 studs long. Pass a third argument to change it, e.g. ..., "GoKart", 8).
  • Grey, untextured model: the importer didn't find Textures\colormap.png next to the FBX. Re-import and tick the texture option in the import window.
  • Back to parts: delete the model from ReplicatedStorage, VehicleTemplates (or ItemModels / MapModels). The parts version returns on the next build.

6. Sounds

Nine CC0 audio packs are in assets\kenney-audio (706 files). I picked one file per game slot and copied them to assets\picks, named after the slot, so the upload is mechanical:

  1. Creator Dashboard, Development Items, Audio, Upload Asset. Upload everything in C:\dev\crazyfare\assets\picks (13 files, all under 10 seconds except Engine).
  2. Each upload shows an id. Paste it into the matching line of Config.Sounds.Ids: Pickup, Deliver, Bail, Splat, Spinout, Boost, Countdown, Go, RoundEnd, Engine. Crash, Buy and LevelUp are extras I will wire once their ids exist.
  3. Ask me to rebuild. Sounds with an id play; the rest stay silent.

Not in these packs: a car horn, a drift screech and a music loop. Those three come from the Creator Store audio library inside Studio (search "car horn", "tire screech", "upbeat loop", filter to Roblox-licensed), which you can use without uploading: paste the asset id the same way.
